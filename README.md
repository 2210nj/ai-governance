# AI vs Machine Learning vs Deep Learning

## Overview

Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL) are closely related, but they are **not interchangeable terms**.

As an **AI Governance professional**, understanding the distinction is important because different technologies introduce different risks, governance requirements, and control considerations.

This document explains:

1. What **AI, ML, and Deep Learning** mean
2. How they **relate to each other**
3. Key **differences** between them
4. **Real-world examples**
5. Why the distinction **matters for AI Governance**

## 1. The Relationship

The simplest way to understand the relationship is:

**Artificial Intelligence (AI)**  
└── **Machine Learning (ML)**  
&emsp;&emsp;└── **Deep Learning (DL)**

### Key Relationship

- **AI** is the broadest concept.
- **Machine Learning (ML)** is a subset of **AI**.
- **Deep Learning (DL)** is a subset of **Machine Learning**.
- However, **not every AI system uses Machine Learning**.
