# Project 01 — AI Technology Classification & Governance Assessment

## Objective

Apply foundational knowledge of **Artificial Intelligence (AI), Machine Learning (ML), Deep Learning (DL), and Generative AI** to real-world business scenarios.

The objective is not to build the AI systems, but to evaluate them from an **AI Governance perspective**.

---

## Business Scenarios

| # | Use Case | Technology |
|---|---|---|
| 1 | Expense approval using predefined rules | Rule-based system |
| 2 | Fraud detection | Machine Learning |
| 3 | Facial recognition | Deep Learning |
| 4 | Customer support chatbot | Generative AI |
| 5 | Employee candidate ranking | Machine Learning |

---

# Assessment Framework

Each use case is evaluated against:

1. Technology type
2. Purpose
3. Data
4. Potential impact
5. Key risks
6. Governance questions
7. Potential controls
8. Human oversight
9. Monitoring requirements
10. Accountability

---

# Use Case 1 — Expense Approval

### Technology

Rule-based automated system.

### Purpose

Automate low-value expense approvals.

### Key Risks

- Incorrect business rules
- Unauthorized rule changes
- Exceptions not being handled
- Lack of auditability

### Governance Considerations

- Rule ownership
- Change management
- Approval workflow
- Audit logs
- Exception handling

---

# Use Case 2 — Fraud Detection

### Technology

Machine Learning.

### Purpose

Identify potentially fraudulent financial transactions.

### Key Risks

- Bias in historical data
- False positives
- False negatives
- Model drift
- Poor data quality

### Governance Considerations

- Data validation
- Model validation
- Performance monitoring
- Bias testing
- Human review
- Incident management

---

# Use Case 3 — Facial Recognition

### Technology

Deep Learning / Computer Vision.

### Purpose

Identify or verify individuals using facial characteristics.

### Key Risks

- Privacy
- Biometric data
- Demographic performance differences
- False matches
- Security
- Misuse

### Governance Considerations

- Legal basis
- Purpose limitation
- Data protection
- Accuracy testing
- Human verification
- Access controls
- Retention controls

---

# Use Case 4 — Customer Support Chatbot

### Technology

Generative AI / Large Language Model (LLM).

### Purpose

Answer customer questions and assist customer service teams.

### Key Risks

- Hallucinations
- Incorrect information
- Privacy leakage
- Prompt injection
- Inappropriate responses
- Intellectual property concerns

### Governance Considerations

- Approved use cases
- Data controls
- Output testing
- Human escalation
- Monitoring
- Incident reporting
- User transparency

---

# Use Case 5 — Candidate Ranking

### Technology

Machine Learning.

### Purpose

Rank job candidates based on information provided during recruitment.

### Key Risks

- Historical bias
- Discrimination
- Proxy variables
- Lack of transparency
- Incorrect rejection
- Over-reliance on automated recommendations

### Governance Considerations

- Fairness testing
- Human oversight
- Explainability
- Data governance
- Candidate notification where applicable
- Appeals / review process
- Ongoing monitoring
